# TCG kártyák (Season 1) – végrehajtási terv

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cél:** A játékos 100/200/300+ pontért 1–3 véletlen kártyát nyithat meg a Game Over képernyőn egy 30 lapos Season 1 gyűjteményből. A lapokat a `/cards` galériában nézheti meg, a kártya részleteiből átmehet a webshop landing oldalára, és a ranglistán egy „Gyűjtők” fül is van.

**Architektúra:**

- **Szerver:**
  - a Supabase sorsol (`open_cards` RPC, a feltöltött `game_results` sorhoz kötve, idempotensen);
  - a kártyák és a felfedések a `user_cards` táblában vannak;
  - az app ebbe a táblába nem írhat.
- **Kliens:**
  - egy perzisztens Zustand store (`useCardsStore`) tartja a gyűjtemény cache-ét és az offline sorokat (`pendingClaims`, `pendingReveals`);
  - a `src/lib/cards.ts` szinkronizál, és a szerver listája mindig felülírja a helyit;
  - a flip egy Reanimated `rotateY` animáció, ami hálózatra nem vár.

**Tech stack:**

- Supabase: Postgres migráció, RLS, security definer függvények, pgTAP;
- Expo SDK 57, Expo Router (modal route), Reanimated 4, `expo-image`, `expo-haptics`, `expo-web-browser`;
- Zustand persist, gluestack-ui + NativeWind, Jest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-10-tcg-cards-design.md`. Olvasd el a feladatok előtt.

## Global Constraints

- Kártyák száma játékonként: `min(3, floor(score / 100))`. 100 → 1, 200 → 2, 300+ → 3, 1000 → 3. 100 pont alatt nincs kártya-szekció.
- Számláló szöveg: „N kártyát nyithatsz meg (S pont)”.
- 30 lap. Mind egyforma eséllyel sorsolódik (1/30). A ritkaság (`common` / `rare` / `legendary`) csak jelvény.
- Duplikátum megengedett. A rácsban a már felfedett lap nem változik.
- A „Season 1/432” csak kiírt szöveg: `cards.serial_label`, alapértéke `Season 1/432`.
- A landing link a `cards.landing_url` oszlopban teljes URL-ként van. Az app nem számol hash-t, `expo-web-browser`-rel nyitja meg.
- A sorsolás mindig a szerveren történik. Offline a nyitási jog a készüléken marad (`pendingClaims`), és a következő szinkron nyitja meg.
- Flip: `rotateY`, 350 ms. Hátlap: logó + „Mystery Card”. Előlap: artwork, név, ritkaság-jelvény, `serial_label`.
- A swiper hátlappal is lapozható. Felfedés után nincs extra animáció.
- A Game Over fő CTA-ja az „Újra játszom”. A webshop felé vezető út másodlagos („Kártya megtekintése →”).
- Galéria: `/cards`. 3 oszlop telefonon, 5 oszlop 600 pt szélességtől. Fejléc: „Season 1 Limited (30 cards)”. Pull-to-refresh: szinkron.
- Részletek: `/cards/[number]`, `presentation: 'modal'`.
- Ranglista: harmadik fül „Gyűjtők”. A különböző felfedett lapok száma szerint, holtversenyben az előbb elért első.
- A játék és a Game Over soha nem vár a hálózatra (`withTimeout`, 5000 ms).
- Parancsok: `npx jest <path>`, `npx tsc --noEmit`, `npx expo lint`. SQL: `npx supabase test db` (Docker kell hozzá).

## Review Focus

1. **Fiókváltás vagy kijelentkezés után beragadt claim.** Ha egy claim eredményét már egy másik fiók töltötte fel, az `open_cards` P0002-t ad, és az eredmény nincs a feltöltésre várók között. Ilyenkor a claimet el kell dobni, nem örökké újrapróbálni. Teszt: a Task 4-ben.
2. **Az eredmény feltöltése még fut, amikor a Game Over megnyílik.** A `claimCards` előbb megvárja a `syncResults`-t. Ha a szerver mégis P0002-t ad és az eredmény még vár a feltöltésre, a claim megmarad, és a képernyő az offline szöveget mutatja. Teszt: a Task 4-ben.
3. **Offline felfedés, aztán szinkron.** A szerver lista nem tüntetheti el a helyben már felfordított lapot, amíg a `reveal_card` nem ért fel. Teszt: a Task 2 (`replaceOwned`) és a Task 4 (`syncCards`).
4. **Kétszeri hívás vagy elveszett válasz.** A második `open_cards` ugyanazokat a lapokat adja vissza, nem sorsol újra. Teszt: a Task 1 pgTAP.
5. **Swiper felfedés közben (galéria).** A „Bontatlan kártyák” nézetben a felfordított lap nem tűnhet el a swiperből flip közben. Ezért a nézet a megnyitáskori id-listát tartja. Teszt: a Task 8.

```sql
-- TCG cards (Season 1): a 30-card collection, cards drawn per game on the
-- server, and a collectors' ranking.
--
-- - cards: content, read by everyone, edited from the dashboard only
-- - user_cards: what each player drew; written only by the functions below,
--   so the app can neither insert nor choose a card
-- - a game earns least(3, score / 100) cards; open_cards draws them once and
--   returns the same cards on every later call (safe to retry)

-- ── cards ───────────────────────────────────────────────────────────────
create table public.cards (
  id text primary key check (id ~ '^[a-z0-9][a-z0-9-]{1,63}$'),
  number integer not null unique check (number between 1 and 999),
  name text not null check (char_length(name) between 1 and 60),
  description text not null check (char_length(description) between 1 and 500),
  rarity text not null default 'common' check (rarity in ('common', 'rare', 'legendary')),
  -- public URL, e.g. from the "cards" storage bucket below
  image_url text check (image_url ~ '^https://'),
  -- the webshop page of the real card (e.g. https://krumplisztan.hu/kartyak/<md5>)
  landing_url text check (landing_url ~ '^https://'),
  season integer not null default 1 check (season >= 1),
  -- display only (print run), e.g. "Season 1/432"
  serial_label text not null default 'Season 1/432' check (char_length(serial_label) between 1 and 40),
  enabled boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

alter table public.cards enable row level security;

create policy "Everyone reads enabled cards"
  on public.cards for select to anon, authenticated
  using (enabled);

revoke insert, update, delete, truncate on public.cards from anon, authenticated;
grant select on public.cards to anon, authenticated;

create trigger cards_touch before update on public.cards
  for each row execute function public.touch_updated_at();

-- card art: public bucket, upload from the dashboard and put the URL into cards.image_url
insert into storage.buckets (id, name, public)
values ('cards', 'cards', true)
on conflict (id) do nothing;

create policy "Everyone reads card images"
  on storage.objects for select to anon, authenticated
  using (bucket_id = 'cards');

-- ── user cards ──────────────────────────────────────────────────────────
create table public.user_cards (
  id bigint generated always as identity primary key,
  user_id uuid not null references public.profiles (id) on delete cascade,
  card_id text not null references public.cards (id),
  -- the game that earned the card (US-6 game_session_id)
  game_result_id bigint not null references public.game_results (id) on delete cascade,
  slot smallint not null check (slot between 1 and 3),
  drawn_at timestamptz not null default now(),
  revealed_at timestamptz,
  unique (game_result_id, slot)
);

create index user_cards_user_id_idx on public.user_cards (user_id);

alter table public.user_cards enable row level security;

create policy "Players read their own cards"
  on public.user_cards for select to authenticated
  using ((select auth.uid()) = user_id);

-- read-only for the app: every write goes through open_cards / reveal_card
revoke all on public.user_cards from anon;
revoke insert, update, delete, truncate on public.user_cards from authenticated;
grant select on public.user_cards to authenticated;

-- ── drawing ─────────────────────────────────────────────────────────────
-- Draws the cards the caller's uploaded result (by its device id) earned and
-- returns all cards of that game. Raises no_data_found (P0002) while the
-- result isn't on the server (not uploaded yet, or another player's).
create function public.open_cards(p_client_id text)
returns setof public.user_cards
language plpgsql
volatile
security definer
set search_path = ''
as $$
declare
  me uuid := (select auth.uid());
  result_id bigint;
  result_score integer;
begin
  if me is null then
    raise exception 'not signed in' using errcode = '42501';
  end if;

  select r.id, r.score into result_id, result_score
  from public.game_results r
  where r.user_id = me and r.client_id = p_client_id;

  if result_id is null then
    raise exception 'result % is not uploaded', p_client_id using errcode = 'P0002';
  end if;

  -- one uniformly random enabled card per missing slot; filled slots stay as they are
  for s in 1..least(3, result_score / 100) loop
    insert into public.user_cards (user_id, card_id, game_result_id, slot)
    select me, c.id, result_id, s
    from public.cards c
    where c.enabled
    order by random()
    limit 1
    on conflict (game_result_id, slot) do nothing;
  end loop;

  return query
    select * from public.user_cards uc where uc.game_result_id = result_id order by uc.slot;
end;
$$;

revoke execute on function public.open_cards(text) from public, anon;
grant execute on function public.open_cards(text) to authenticated;

-- marks one of the caller's cards revealed (flipped); no-op for anyone else's
create function public.reveal_card(p_user_card_id bigint)
returns void
language sql
volatile
security definer
set search_path = ''
as $$
  update public.user_cards
  set revealed_at = now()
  where id = p_user_card_id
    and user_id = (select auth.uid())
    and revealed_at is null
$$;

revoke execute on function public.reveal_card(bigint) from public, anon;
grant execute on function public.reveal_card(bigint) to authenticated;

-- ── collectors' ranking ─────────────────────────────────────────────────
-- each player's distinct revealed cards, and when they revealed the newest one
create function public.collector_counts()
returns table (user_id uuid, distinct_cards integer, reached_at timestamptz)
language sql
stable
security definer
set search_path = ''
as $$
  select f.user_id, count(*)::integer, max(f.first_at)
  from (
    select uc.user_id, uc.card_id, min(uc.revealed_at) as first_at
    from public.user_cards uc
    where uc.revealed_at is not null
    group by uc.user_id, uc.card_id
  ) f
  group by f.user_id
$$;

revoke execute on function public.collector_counts() from public, anon, authenticated;

-- most distinct cards first, then who got there first (max 100 rows)
create function public.top_collectors(limit_count integer default 10)
returns table (user_id uuid, display_name text, distinct_cards integer, reached_at timestamptz)
language sql
stable
security definer
set search_path = ''
as $$
  select c.user_id, p.display_name, c.distinct_cards, c.reached_at
  from public.collector_counts() c
  join public.profiles p on p.id = c.user_id
  order by c.distinct_cards desc, c.reached_at asc
  limit least(greatest(limit_count, 1), 100)
$$;

revoke execute on function public.top_collectors(integer) from public;
grant execute on function public.top_collectors(integer) to anon, authenticated;

-- the signed-in player's row in the ranking (no row before their first reveal)
create function public.my_collector_rank()
returns table (display_name text, distinct_cards integer, reached_at timestamptz, rank bigint)
language sql
stable
security definer
set search_path = ''
as $$
  select p.display_name, me.distinct_cards, me.reached_at,
    (select count(*) + 1 from public.collector_counts() o
      where o.distinct_cards > me.distinct_cards
         or (o.distinct_cards = me.distinct_cards and o.reached_at < me.reached_at)) as rank
  from public.collector_counts() me
  join public.profiles p on p.id = me.user_id
  where me.user_id = (select auth.uid())
$$;

revoke execute on function public.my_collector_rank() from public, anon;
grant execute on function public.my_collector_rank() to authenticated;

-- ── initial content: 30 placeholders, replaced from the dashboard ──────
insert into public.cards (id, number, name, description, rarity)
select
  'card-' || lpad(n::text, 2, '0'),
  n,
  'Kártya #' || n,
  'Helyőrző kártya. A valódi tartalom hamarosan érkezik.',
  case when n > 27 then 'legendary' when n > 20 then 'rare' else 'common' end
from generate_series(1, 30) n
on conflict (id) do nothing;
```

```ts
/**
 * Season 1 card rules that don't need the network: how many cards a game
 * earns, the app-side types, the gallery grid, and how the server's list is
 * merged into the device's copy (the server wins, except for a reveal made on
 * this device that hasn't been sent yet).
 */
import type { Database } from "./database.types";

type CardRow = Database["public"]["Tables"]["cards"]["Row"];
type UserCardRow = Database["public"]["Tables"]["user_cards"]["Row"];

export const MAX_CARDS_PER_GAME = 3;
export const POINTS_PER_CARD = 100;

export type Rarity = CardRow["rarity"];

export type Card = {
  id: string;
  number: number;
  name: string;
  description: string;
  rarity: Rarity;
  imageUrl: string | null;
  landingUrl: string | null;
  serialLabel: string;
};

/** One drawn copy (duplicates are separate rows). */
export type OwnedCard = {
  id: number;
  cardId: string;
  gameResultId: number;
  slot: number;
  revealedAt: string | null;
};

export type GridCell = { card: Card; revealed: boolean };

/** 100+ points → 1, 200+ → 2, 300+ → 3 (the server applies the same rule). */
export function cardsForScore(score: number): number {
  if (!Number.isFinite(score) || score <= 0) return 0;
  return Math.min(MAX_CARDS_PER_GAME, Math.floor(score / POINTS_PER_CARD));
}

export function rowToCard(row: CardRow): Card {
  return {
    id: row.id,
    number: row.number,
    name: row.name,
    description: row.description,
    rarity: row.rarity,
    imageUrl: row.image_url,
    landingUrl: row.landing_url,
    serialLabel: row.serial_label,
  };
}

export function rowToOwned(row: UserCardRow): OwnedCard {
  return {
    id: row.id,
    cardId: row.card_id,
    gameResultId: row.game_result_id,
    slot: row.slot,
    revealedAt: row.revealed_at,
  };
}

export function revealedCardIds(owned: OwnedCard[]): Set<string> {
  return new Set(owned.filter((o) => o.revealedAt).map((o) => o.cardId));
}

/** Every card of the collection by number, open if any copy of it is revealed. */
export function buildGrid(catalog: Card[], owned: OwnedCard[]): GridCell[] {
  const revealed = revealedCardIds(owned);
  return [...catalog]
    .sort((a, b) => a.number - b.number)
    .map((card) => ({ card, revealed: revealed.has(card.id) }));
}

/** Distinct revealed cards (e.g. the 12 in "12/30"). */
export function collectedCount(catalog: Card[], owned: OwnedCard[]): number {
  const revealed = revealedCardIds(owned);
  return catalog.filter((c) => revealed.has(c.id)).length;
}

/** Drawn but not flipped yet, oldest first. */
export function unrevealed(owned: OwnedCard[]): OwnedCard[] {
  return owned.filter((o) => !o.revealedAt).sort((a, b) => a.id - b.id);
}

/** The server's list replaces the local one; a local reveal still being sent is kept. */
export function replaceOwned(
  previous: OwnedCard[],
  server: OwnedCard[],
  pendingReveals: number[],
): OwnedCard[] {
  const before = new Map(previous.map((o) => [o.id, o]));
  const pending = new Set(pendingReveals);
  return server.map((o) =>
    o.revealedAt || !pending.has(o.id)
      ? o
      : { ...o, revealedAt: before.get(o.id)?.revealedAt ?? null },
  );
}

/** Adds the cards open_cards returned (and updates any already known), oldest first. */
export function mergeDrawn(
  previous: OwnedCard[],
  drawn: OwnedCard[],
  pendingReveals: number[],
): OwnedCard[] {
  const updated = replaceOwned(previous, drawn, pendingReveals);
  const ids = new Set(updated.map((o) => o.id));
  return [...previous.filter((o) => !ids.has(o.id)), ...updated].sort(
    (a, b) => a.id - b.id,
  );
}
```

```ts
import AsyncStorage from "@react-native-async-storage/async-storage";
import { create } from "zustand";
import { createJSONStorage, persist } from "zustand/middleware";

import {
  mergeDrawn,
  replaceOwned,
  type Card,
  type OwnedCard,
} from "@/lib/cardRules";

type CardsState = {
  /** The collection's cards as last downloaded (kept for offline use). */
  catalog: Card[];
  /** This player's drawn copies as last known; the server's list replaces it on sync. */
  owned: OwnedCard[];
  /** Device ids of games that earned cards not drawn yet (e.g. offline at game over). */
  pendingClaims: string[];
  /** Cards flipped on this device whose reveal hasn't reached the server yet. */
  pendingReveals: number[];
  addClaim: (clientId: string) => void;
  removeClaim: (clientId: string) => void;
  setCatalog: (cards: Card[]) => void;
  setOwned: (server: OwnedCard[]) => void;
  addDrawn: (drawn: OwnedCard[]) => void;
  revealLocal: (id: number) => void;
  confirmReveals: (ids: number[]) => void;
};

export const useCardsStore = create<CardsState>()(
  persist(
    (set) => ({
      catalog: [],
      owned: [],
      pendingClaims: [],
      pendingReveals: [],
      addClaim: (clientId) =>
        set((s) =>
          s.pendingClaims.includes(clientId)
            ? s
            : { pendingClaims: [...s.pendingClaims, clientId] },
        ),
      removeClaim: (clientId) =>
        set((s) => ({
          pendingClaims: s.pendingClaims.filter((id) => id !== clientId),
        })),
      setCatalog: (catalog) => set({ catalog }),
      setOwned: (server) =>
        set((s) => ({
          owned: replaceOwned(s.owned, server, s.pendingReveals),
        })),
      addDrawn: (drawn) =>
        set((s) => ({ owned: mergeDrawn(s.owned, drawn, s.pendingReveals) })),
      revealLocal: (id) =>
        set((s) => {
          const target = s.owned.find((o) => o.id === id);
          if (!target || target.revealedAt) return s;
          const revealedAt = new Date().toISOString();
          return {
            owned: s.owned.map((o) => (o.id === id ? { ...o, revealedAt } : o)),
            pendingReveals: [...s.pendingReveals, id],
          };
        }),
      confirmReveals: (ids) =>
        set((s) => ({
          pendingReveals: s.pendingReveals.filter((id) => !ids.includes(id)),
        })),
    }),
    {
      name: "hiperventi-cards",
      storage: createJSONStorage(() => AsyncStorage),
      partialize: (s) => ({
        catalog: s.catalog,
        owned: s.owned,
        pendingClaims: s.pendingClaims,
        pendingReveals: s.pendingReveals,
      }),
    },
  ),
);
```

```ts
/**
 * Season 1 cards: drawing them for a game, revealing them, and keeping the
 * device's copy of the collection in step with the server.
 *
 * The server draws every card (open_cards), so the app can neither pick nor
 * invent one. Games that earned cards while offline wait in pendingClaims,
 * reveals made offline in pendingReveals; both are retried on the next sync.
 * The server's list always replaces the device's (only a reveal not sent yet
 * is kept). Nothing here throws or blocks the game.
 */
import type { SupabaseClient } from "@supabase/supabase-js";
import { AppState } from "react-native";

import { selectPendingUploads, useAppStore } from "@/store/useAppStore";
import { useAuthStore } from "@/store/useAuthStore";
import { useCardsStore } from "@/store/useCardsStore";

import { ensureSignedIn } from "./auth";
import { rowToCard, rowToOwned, type OwnedCard } from "./cardRules";
import type { Database } from "./database.types";
import { syncResults } from "./resultsSync";
import { getSupabase } from "./supabase";
import { withTimeout } from "./withTimeout";

const TIMEOUT_MS = 5000;
/** Postgres no_data_found: open_cards didn't find the result on the server. */
const RESULT_NOT_FOUND = "P0002";

export type CardSyncStatus = "ok" | "offline" | "error";
export type ClaimResult = { status: CardSyncStatus; cards: OwnedCard[] };

async function loadCatalog(supabase: SupabaseClient<Database>) {
  const { data, error } = await withTimeout(
    supabase.from("cards").select("*").eq("enabled", true).order("number"),
    TIMEOUT_MS,
  );
  if (error) throw error;
  useCardsStore.getState().setCatalog(data.map(rowToCard));
}

/** Draws (or fetches the already drawn) cards of one game, uploading its result first. */
export async function claimCards(clientId: string): Promise<ClaimResult> {
  const supabase = getSupabase();
  if (!supabase || (await ensureSignedIn()) !== "signedIn")
    return { status: "offline", cards: [] };
  try {
    await syncResults();
    const { data, error } = await withTimeout(
      supabase.rpc("open_cards", { p_client_id: clientId }),
      TIMEOUT_MS,
    );
    if (error) {
      if (error.code !== RESULT_NOT_FOUND) throw error;
      // still waiting for upload → try again later; otherwise it can never be opened (e.g. another account's)
      const waiting = selectPendingUploads(useAppStore.getState()).some(
        (r) => r.id === clientId,
      );
      if (waiting) return { status: "offline", cards: [] };
      useCardsStore.getState().removeClaim(clientId);
      return { status: "error", cards: [] };
    }
    const cards = data.map(rowToOwned);
    const store = useCardsStore.getState();
    store.addDrawn(cards);
    store.removeClaim(clientId);
    if (cards.some((c) => !store.catalog.some((k) => k.id === c.cardId))) {
      await loadCatalog(supabase).catch((e) =>
        console.warn("Card list download failed", e),
      );
    }
    return { status: "ok", cards };
  } catch (e) {
    console.warn("Opening cards failed, will retry later", e);
    return { status: "error", cards: [] };
  }
}

async function sendReveals(ids: number[]) {
  const supabase = getSupabase();
  if (
    !supabase ||
    useAuthStore.getState().status !== "signedIn" ||
    ids.length === 0
  )
    return;
  const done: number[] = [];
  for (const id of ids) {
    try {
      const { error } = await withTimeout(
        supabase.rpc("reveal_card", { p_user_card_id: id }),
        TIMEOUT_MS,
      );
      if (!error) done.push(id);
    } catch {
      // offline: retried on the next sync
    }
  }
  useCardsStore.getState().confirmReveals(done);
}

/** Flips a card: revealed on this device at once, on the server as soon as possible. */
export async function revealCard(userCardId: number): Promise<void> {
  useCardsStore.getState().revealLocal(userCardId);
  await sendReveals([userCardId]);
}

let running: Promise<CardSyncStatus> | null = null;

/** Opens queued games, sends queued reveals, then takes the server's collection. */
export function syncCards(): Promise<CardSyncStatus> {
  running ??= sync().finally(() => {
    running = null;
  });
  return running;
}

async function sync(): Promise<CardSyncStatus> {
  const supabase = getSupabase();
  if (!supabase || (await ensureSignedIn()) !== "signedIn") return "offline";
  for (const clientId of useCardsStore.getState().pendingClaims)
    await claimCards(clientId);
  await sendReveals(useCardsStore.getState().pendingReveals);
  try {
    const [, owned] = await Promise.all([
      loadCatalog(supabase),
      withTimeout(
        supabase.from("user_cards").select("*").order("id"),
        TIMEOUT_MS,
      ),
    ]);
    if (owned.error) throw owned.error;
    useCardsStore.getState().setOwned(owned.data.map(rowToOwned));
    return "ok";
  } catch (e) {
    console.warn("Card sync failed, showing the cached collection", e);
    return "error";
  }
}

let watchingForeground = false;

/** Syncs now and whenever the app comes back to the foreground. */
export function startCardSync() {
  syncCards();
  if (watchingForeground) return;
  watchingForeground = true;
  AppState.addEventListener("change", (state) => {
    if (state === "active") syncCards();
  });
}
```

```tsx
import * as Haptics from "expo-haptics";
import { useEffect } from "react";
import { Pressable, StyleSheet } from "react-native";
import Animated, {
  interpolate,
  useAnimatedStyle,
  useSharedValue,
  withTiming,
} from "react-native-reanimated";

import { playSound } from "@/lib/audio";
import type { Card } from "@/lib/cardRules";

import { CARD_ASPECT, CardBack, CardFront } from "./CardFaces";

export const FLIP_MS = 350;

type Props = {
  /** Unknown (e.g. the collection isn't downloaded yet): only the back, can't be flipped. */
  card?: Card;
  revealed: boolean;
  width: number;
  onReveal: () => void;
};

/** A card that turns from its back to its front around the Y axis when tapped. */
export function FlipCard({ card, revealed, width, onReveal }: Props) {
  const turn = useSharedValue(revealed ? 1 : 0);

  useEffect(() => {
    turn.set(withTiming(revealed ? 1 : 0, { duration: FLIP_MS }));
  }, [revealed, turn]);

  const backStyle = useAnimatedStyle(() => ({
    transform: [
      { perspective: 800 },
      { rotateY: `${interpolate(turn.get(), [0, 1], [0, 180])}deg` },
    ],
  }));
  const frontStyle = useAnimatedStyle(() => ({
    transform: [
      { perspective: 800 },
      { rotateY: `${interpolate(turn.get(), [0, 1], [180, 360])}deg` },
    ],
  }));

  const canFlip = !revealed && card !== undefined;
  const flip = () => {
    if (!canFlip) return;
    Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light);
    playSound("card");
    onReveal();
  };

  return (
    <Pressable
      onPress={flip}
      accessibilityRole="button"
      accessibilityLabel={
        revealed && card ? card.name : "Mystery Card, koppints a felfordításhoz"
      }
      style={{ width, height: width / CARD_ASPECT }}
    >
      <Animated.View style={[styles.face, backStyle]}>
        <CardBack />
      </Animated.View>
      {card && (
        <Animated.View
          style={[styles.face, frontStyle]}
          accessibilityElementsHidden={!revealed}
          importantForAccessibility={revealed ? "auto" : "no-hide-descendants"}
        >
          <CardFront card={card} />
        </Animated.View>
      )}
    </Pressable>
  );
}

const styles = StyleSheet.create({
  face: { ...StyleSheet.absoluteFillObject, backfaceVisibility: "hidden" },
});
```

```tsx
import { useState } from "react";
import {
  FlatList,
  View,
  type NativeScrollEvent,
  type NativeSyntheticEvent,
} from "react-native";

import { Box } from "@/components/ui/box";
import { HStack } from "@/components/ui/hstack";
import type { Card, OwnedCard } from "@/lib/cardRules";

import { FlipCard } from "./FlipCard";

export type SwiperItem = { owned: OwnedCard; card?: Card };

type Props = {
  items: SwiperItem[];
  onReveal: (userCardId: number) => void;
  onIndexChange?: (index: number) => void;
};

/** One card per page, swipeable also while the cards still show their backs. */
export function CardSwiper({ items, onReveal, onIndexChange }: Props) {
  const [width, setWidth] = useState(0);
  const [index, setIndex] = useState(0);
  const cardWidth = Math.min(width * 0.7, 240);

  const onPageEnd = (e: NativeSyntheticEvent<NativeScrollEvent>) => {
    if (width === 0) return;
    const page = Math.round(e.nativeEvent.contentOffset.x / width);
    if (page === index) return;
    setIndex(page);
    onIndexChange?.(page);
  };

  return (
    <View
      testID="card-swiper"
      onLayout={(e) => setWidth(e.nativeEvent.layout.width)}
      style={{ width: "100%" }}
    >
      {width > 0 && (
        <FlatList
          testID="card-swiper-list"
          horizontal
          pagingEnabled
          showsHorizontalScrollIndicator={false}
          data={items}
          keyExtractor={(item) => String(item.owned.id)}
          onMomentumScrollEnd={onPageEnd}
          renderItem={({ item }) => (
            <View style={{ width, alignItems: "center" }}>
              <FlipCard
                card={item.card}
                revealed={item.owned.revealedAt !== null}
                width={cardWidth}
                onReveal={() => onReveal(item.owned.id)}
              />
            </View>
          )}
        />
      )}
      {items.length > 1 && (
        <HStack space="xs" className="mt-3 justify-center">
          {items.map((item, i) => (
            <Box
              key={item.owned.id}
              className={`h-2 w-2 rounded-full ${i === index ? "bg-foreground" : "bg-muted-foreground/40"}`}
            />
          ))}
        </HStack>
      )}
    </View>
  );
}
```

```tsx
import { router } from "expo-router";
import { useEffect, useState } from "react";

import { Button, ButtonText } from "@/components/ui/button";
import { Spinner } from "@/components/ui/spinner";
import { Text } from "@/components/ui/text";
import { VStack } from "@/components/ui/vstack";
import { cardsForScore } from "@/lib/cardRules";
import { claimCards, revealCard } from "@/lib/cards";
import { useCardsStore } from "@/store/useCardsStore";

import { CardSwiper, type SwiperItem } from "./CardSwiper";

type Claim =
  | { state: "loading" }
  | { state: "ready"; ids: number[] }
  | { state: "offline" }
  | { state: "error" };

/**
 * The game over screen's card section: how many cards the score earned, then
 * the drawn cards in a swiper to flip. The draw starts as soon as the screen
 * opens; offline the game stays queued and opens later (menu / collection).
 */
export function GameOverCards({
  resultId,
  score,
}: {
  resultId?: string;
  score: number;
}) {
  const count = cardsForScore(score);
  const [claim, setClaim] = useState<Claim>({ state: "loading" });
  const [open, setOpen] = useState(false);
  const [index, setIndex] = useState(0);
  const owned = useCardsStore((s) => s.owned);
  const catalog = useCardsStore((s) => s.catalog);

  useEffect(() => {
    if (!resultId || count === 0) return;
    let alive = true;
    claimCards(resultId).then((r) => {
      if (!alive) return;
      if (r.status === "ok")
        setClaim({ state: "ready", ids: r.cards.map((c) => c.id) });
      else setClaim({ state: r.status });
    });
    return () => {
      alive = false;
    };
  }, [resultId, count]);

  if (!resultId || count === 0) return null;

  // read from the store, so a flip shows at once
  const items: SwiperItem[] =
    claim.state === "ready"
      ? claim.ids.flatMap((id) => {
          const o = owned.find((x) => x.id === id);
          return o
            ? [{ owned: o, card: catalog.find((c) => c.id === o.cardId) }]
            : [];
        })
      : [];
  const current = open ? items[index] : undefined;

  return (
    <VStack space="md" className="items-center border-t border-border pt-4">
      <Text className="text-center text-foreground">
        {count} kártyát nyithatsz meg ({score} pont)
      </Text>
      {claim.state === "offline" || claim.state === "error" ? (
        <Text size="sm" className="text-center text-muted-foreground">
          {claim.state === "offline"
            ? "Csatlakozz a kártyák megnyitásához — megőrizzük őket."
            : "Most nem sikerült megnyitni a kártyákat."}
        </Text>
      ) : claim.state === "loading" ? (
        <Spinner />
      ) : open ? (
        <CardSwiper
          items={items}
          onReveal={revealCard}
          onIndexChange={setIndex}
        />
      ) : (
        <Button
          variant="outline"
          className="w-full"
          onPress={() => setOpen(true)}
        >
          <ButtonText>Kártyák megnyitása</ButtonText>
        </Button>
      )}
      {current?.card && current.owned.revealedAt && (
        <VStack space="sm" className="w-full items-center">
          <Text size="sm" className="text-center text-foreground">
            A valódi kártyát is megismerheted!
          </Text>
          <Button
            variant="outline"
            className="w-full"
            onPress={() => router.push(`/cards/${current.card!.number}`)}
          >
            <ButtonText>Kártya megtekintése →</ButtonText>
          </Button>
        </VStack>
      )}
    </VStack>
  );
}
```

```ts
/**
 * Collectors' ranking: players by how many different Season 1 cards they
 * revealed; on a tie, whoever got there first. Same board shape as the score
 * leaderboard (top 10, the own row highlighted or appended with its rank).
 */
import { useAuthStore } from "@/store/useAuthStore";

import {
  BOARD_SIZE,
  buildBoard,
  OfflineError,
  type Board,
  type OwnEntry,
  type TopEntry,
} from "./leaderboard";
import { getSupabase } from "./supabase";

export async function fetchCollectors(): Promise<Board> {
  const supabase = getSupabase();
  if (!supabase) throw new OfflineError("no backend");

  const top = await supabase.rpc("top_collectors", { limit_count: BOARD_SIZE });
  if (top.error) throw top.error;
  const entries: TopEntry[] = top.data.map((t) => ({
    userId: t.user_id,
    name: t.display_name,
    score: t.distinct_cards,
    playedAt: t.reached_at,
  }));

  const { status, userId } = useAuthStore.getState();
  let own: OwnEntry | null = null;
  if (status === "signedIn" && userId) {
    const mine = await supabase.rpc("my_collector_rank");
    if (mine.error) throw mine.error;
    const row = mine.data[0];
    if (row)
      own = {
        name: row.display_name,
        score: row.distinct_cards,
        playedAt: row.reached_at,
        rank: row.rank,
        userId,
      };
  }
  return buildBoard(entries, own);
}
```
